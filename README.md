# National Road Accidents Dashboard | Power BI

## Overview
This project presents an interactive Power BI dashboard developed to analyze national road accident data. The dashboard helps identify accident trends, severity patterns, and high-risk regions to support data-driven decision-making.

## Tools & Technologies
- Power BI  
- DAX  
- Power Query  

## Key Features
- State-wise and year-wise accident analysis  
- Trend and severity distribution insights  
- Interactive filters and slicers for dynamic exploration  

## Data Processing
- Cleaned and transformed raw data using Power Query  
- Created calculated measures and KPIs using DAX  
- Modeled data for efficient analysis and visualization  

## Use Case
The dashboard can assist policymakers, researchers, and traffic authorities in identifying accident-prone regions and understanding underlying trends for improved road safety planning.
